# 📜 Digital Edition: 19th-Century Literary Journal
A digital humanities project that encodes, structures, and visualizes five historical articles from a 19th-century literary journal. Built using XML technologies to transform unstructured archival texts into a fully navigable web-based critical edition.

## 🚀 Features
* **TEI-Compliant XML Text Encoding:** Structurally and semantically marks up the body text of five 19th-century articles, preserving physical layout, editorial interventions, and textual phenomena.
* **Linked Named Entity Authority File:** Utilizes a dedicated XML authority database to index, contextualize, and link historical figures, geographic locations, and literary works back to the main text.
* **Automated XSLT-to-HTML Transformation:** Converts complex XML and authority data into a clean, modern, and accessible web interface via a custom XSLT stylesheet.

## 🛠️ Tech Stack
* **Markup & Structure:** XML (TEI P5 Guidelines)
* **Transformation & Processing:** XSLT 2.0, XPath
* **Styling & Presentation:** HTML5, CSS3 , JavaScript (ES6+)
